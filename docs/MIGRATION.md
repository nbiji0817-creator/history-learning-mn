# Хуучин контентыг нүүлгэсэн тэмдэглэл

## Юу болсон бэ?

Төслийн эхэнд `app/6`, `app/7`, `app/8`, `app/9`, `app/10` фолдер тус бүрдээ
өөрийн `data.ts`, хичээлийн хуудас, толь бичиг, тест зэргийг агуулж байсан.
Энэ нь дараах асуудлыг үүсгэж байв:

- Хичээлийн өгөгдөл анги бүрд өөр өөр бүтэцтэй (`chapterTitle` байгаа/байхгүй)
- Нэг хичээлийн жагсаалт хэд хэдэн файлд давхардсан
- Ахиц, XP, AI, хайлт зэрэг нийтлэг систем нь тэдгээр өгөгдлийг мэдэхгүй
- Supabase руу шилжүүлэхэд хүснэгтийн бүтэц тодорхойгүй

Иймд бүх контентыг нэг дата давхарга (`data/`) руу нэгтгэв.

## Юуг нүүлгэсэн бэ?

| Эх сурвалж | Хаашаа | Хэмжээ |
|---|---|---|
| `app/7/data.ts` | `data/lessons/grade7-textbook.ts` | 35 хичээл |
| `app/8/data.ts` | `data/lessons/grade8-textbook.ts` | 26 хичээл |
| `app/9/data.ts` | `data/lessons/grade9-textbook.ts` | 32 хичээл |
| `app/10/lesson/[id]/page.tsx` | `data/lessons/grade10-textbook.ts` | 15 хичээл |
| 7–9-р ангийн тестүүд | `data/questions-textbook.ts` | 385 асуулт |
| `app/10/dictionary/page.tsx` | `data/glossary-textbook.ts` | 25 нэр томьёо |
| `app/10/sources/page.tsx` | `data/sources-textbook.ts` | 8 эх сурвалж |

**Эх файлуудыг өөрчлөөгүй, устгаагүй** — зөвхөн уншиж хуулбарласан.

## Талбар хэрхэн хөрвөсөн бэ?

Хуучин бүтэц:

```ts
{ id, chapter, chapterTitle?, title, pages, icon, summary, keyPoints, questions }
```

Шинэ `Lesson` бүтэц рүү:

| Хуучин | Шинэ | Тайлбар |
|---|---|---|
| `title` | `title` | шууд |
| `chapter` / `chapterTitle` | `subtitle`, `tags[0]` | `chapters` массиваас нэрийг нь олсон |
| `summary` | `summary` + `sections[0].body` | |
| `keyPoints` | `objectives` (эхний 4) + `sections[1].points` | шинэ `keypoints` секцийн төрөл нэмсэн |
| `pages` | `conclusion`, `question.source` | сурах бичгийн хуудасны заалт хадгалагдсан |
| `questions[]` | `data/questions-textbook.ts` | `tags: [lessonSlug]` — тестийг автоматаар угсарна |
| — | `slug` | гарчгийг латинаар галиглаж үүсгэсэн |

### Автоматаар үүсгэсэн талбарууд

Эх өгөгдөлд байхгүй байсан тул дараах талбарыг үүсгэсэн:

- **`explanation`** — хуучин тестэд тайлбар байгаагүй. Одоо
  `Зөв хариулт: «…». Дэлгэрэнгүйг «<хичээл>» хичээлээс (сурах бичиг N-р хуудас)`
  гэсэн хэлбэрээр үүснэ. Багш үүнийг гараар баяжуулах боломжтой.
- **`difficulty: "medium"`** — түвшин заагаагүй байсан.
- **`durationMinutes: 30`** — тооцоолсон дундаж.

## Хичээлийн дараалал

`data/lessons/index.ts` дотор хоёр бүлэг байна:

1. **Сурах бичгийн хичээл** (7–10-р анги) — `order: 1..N`, үндсэн хөтөлбөр
2. **Нэмэлт хичээл** — гараар бичсэн, инфографик/газрын зураг/он цагийн
   хэлхээстэй сэдэвчилсэн хичээлүүд. `order: 100+`, `tags`-д `"нэмэлт"`.

6, 11, 12-р ангид сурах бичгийн хувилбар байхгүй тул тэдгээрийн хичээл нь
үндсэн хөтөлбөр хэвээр байна.

## Дахин ажиллуулах

Хэрэв `app/7–10` доторх өгөгдөл өөрчлөгдвөл нүүлгэлтийг дахин хийж болно.
Скрипт нь `scripts/migrate-legacy.cjs` дотор байна:

```bash
node scripts/migrate-legacy.cjs .
```

⚠️ Энэ нь `data/lessons/grade*-textbook.ts`, `data/questions-textbook.ts`,
`data/glossary-textbook.ts`, `data/sources-textbook.ts` файлуудыг **дарж
бичнэ**. Тэдгээрт гараар оруулсан засвар байвал алдагдана — засварыг
`data/lessons/grade*.ts` (нэмэлт хичээл) дотор хийхийг зөвлөнө.

## Хийгээгүй зүйл

- **`app/10/timeline/page.tsx` доторх 16 үйл явдал** нүүгээгүй. Учир нь
  `year` талбар нь `"800 000 жилийн өмнө"` мэтээр бичигдсэн бөгөөд
  эрэмбэлэх тоон утга (`sortYear`) байхгүй. `data/events.ts` дотор аль
  хэдийн 45 үйл явдал бүтэн бүтэцтэй (шалтгаан/явц/үр дүн/ач холбогдол)
  байгаа тул давхардуулахаас сэргийлэв. Шаардлагатай бол гараар нэмнэ.
- **`app/10/games/page.tsx`, `app/10/exams/page.tsx`** — эдгээр нь өгөгдөл
  биш, UI логик агуулсан тул шинэ `/games`, `/exams` хэсэг рүү шилжсэн.
- **`app/6`** — доторх 7 хичээл нь зөвхөн гарчиг, тайлбартай байсан
  (агуулгагүй) тул `data/lessons/grade6.ts` доторх бүтэн хичээлээр сольсон.

## Хуучин зам

`app/6/*` нь `/grades/6` руу redirect хийдэг болсон. `app/7`–`app/10` нь
хэвээр байгаа. Контент нүүсэн тул тэдгээрийг устгаж, redirect болгох нь
зүйтэй — гэхдээ энэ шийдвэрийг эзэн нь гаргана.
